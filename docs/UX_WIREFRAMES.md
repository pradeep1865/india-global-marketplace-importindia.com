# UI Wireframes and Design System

## Design Language

ImportIndia.com uses a white, deep blue, and saffron accent palette. The interface is compact, premium, and operational: sticky search, dense product data, verified trust cues, fast filters, and restrained motion.

## Home

- Sticky top header with global search, delivery country, language, cart, notifications, sign in, create account.
- Left sidebar with Home, Filters, Add Your Listing, Sort, Categories, Verified Manufacturers, and Logistics Calculator.
- Infinite marketplace feed with manufacturer cards, product strip, ratings, MOQ, price, country, delivery timeline.
- Guest users can browse and add to wishlist but are prompted to sign in for listing, checkout, and messaging.

## Auth

- Login supports email/password, Google, Facebook, forgot password, OTP entry, and CAPTCHA slot.
- Registration uses segmented account type selector: Buyer or Manufacturer.
- Manufacturer registration sets account to pending verification.

## Admin

- Secure dashboard with verification queue, moderation queue, payment monitoring, fraud alerts, search analytics, growth, and revenue.
- Every sensitive action opens a confirmation modal and writes an admin audit log.

## Mobile

- Header becomes search-first.
- Sidebar collapses into bottom navigation and filter drawer.
- Cards become single-column with sticky sort/filter controls.
